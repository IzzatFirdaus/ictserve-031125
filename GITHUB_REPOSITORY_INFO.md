# Maklumat Repositori GitHub

## Description (Penerangan)

```
Sistem Pengurusan Aset ICT yang komprehensif untuk BPM MOTAC dengan sokongan dwibahasa, pematuhan WCAG 2.2 AA, dan integrasi MyDS. Dibangunkan menggunakan Laravel 12, Filament 4.1, dan Livewire 3.6 dengan ciri-ciri keselamatan peringkat enterprise, sistem helpdesk, pengurusan pinjaman aset, dan pelaporan analitik masa nyata.
```

## Website (Laman Web)

```
https://ictserve.motac.gov.my
```

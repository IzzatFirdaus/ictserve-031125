TEST GROUPING STRATEGY
=======================

Create these groups:

@group('requires-redis')
  - All Redis/ tests
  - Queue integration tests
  - Horizon tests

@group('requires-wsl')
  - HorizonWSLRedisTest
  - Other WSL-specific tests

@group('requires-horizon')
  - HorizonIntegrationTest
  - Horizon dashboard tests

@group('environment-specific')
  - XamppEnvironmentTest
  - Local development tests

@group('accessibility')
  - WCAG compliance tests
  - Can run separately for focused testing

COMMON PHPUNIT PATTERNS
========================

Skip test conditionally:
```php
if (!condition) {
    $this->markTestSkipped('Reason');
}
```

Group annotation:
```php
use PHPUnit\Framework\Attributes\Group;

#[Group('requires-redis')]
class MyTest extends TestCase
```

Environment check:
```php
protected function setUp(): void
{
    parent::setUp();
    if (env('CI') === true) {
        $this->markTestSkipped('Skip in CI');
    }
}
```

TROUBLESHOOTING
===============

Test hangs:
  - Check for infinite loops
  - Check for blocking I/O
  - Add timeout: php artisan test --timeout=30

Memory issues:
  - Run without parallel: php artisan test
  - Increase memory: php -d memory_limit=512M artisan test

Database locked:
  - Find and kill specific PHP process by PID
  - Clear test database: php artisan db:wipe --env=testing

Cache issues:
  - Clear all: php artisan optimize:clear
  - Clear config: php artisan config:clear
  - Clear events: php artisan event:clear

# Panduan Mula Pantas ICTServe v3.6.0

**Versi**: 3.6.0  
**Tarikh Kemaskini**: 16 Disember 2025  
**Sistem**: ICTServe - Portal Perkhidmatan ICT MOTAC

---

## Selamat Datang ke ICTServe

ICTServe adalah sistem pengurusan perkhidmatan ICT dalaman untuk kakitangan MOTAC. Panduan ini akan membantu anda memulakan penggunaan sistem dengan cepat.

---

## 🚀 Mula Dengan Cepat

### Pilihan 1: Akses Pantas (Tanpa Log Masuk)

Untuk keperluan segera, anda boleh menggunakan sistem tanpa perlu mendaftar:

| Perkhidmatan | Pautan | Penerangan |
|--------------|--------|------------|
| **Tiket Bantuan** | [ictserve.motac.gov.my/helpdesk](https://ictserve.motac.gov.my/helpdesk) | Laporkan masalah ICT |
| **Pinjaman Aset** | [ictserve.motac.gov.my/loan](https://ictserve.motac.gov.my/loan) | Mohon pinjaman peralatan |
| **Semak Status** | [ictserve.motac.gov.my/status](https://ictserve.motac.gov.my/status) | Jejak permohonan sedia ada |

### Pilihan 2: Daftar Akaun (Ciri Lanjutan)

Untuk akses penuh dengan papan pemuka peribadi:

1. Layari **[ictserve.motac.gov.my/register](https://ictserve.motac.gov.my/register)**
2. Masukkan e-mel rasmi @motac.gov.my
3. Lengkapkan pendaftaran
4. Sahkan e-mel anda
5. Log masuk dan nikmati ciri-ciri lanjutan!

## 📝 Hantar Tiket Bantuan Teknikal

### Langkah Mudah (3 Minit)

```
1. Layari ictserve.motac.gov.my/helpdesk
2. Isi maklumat anda (nama, e-mel, bahagian)
3. Pilih kategori masalah
4. Terangkan masalah anda
5. Klik "Hantar"
6. Simpan nombor tiket yang diberikan!
```

### Kategori Masalah

| Kategori | Contoh Masalah |
|----------|----------------|
| **Perkakasan** | Komputer rosak, pencetak tidak berfungsi |
| **Perisian** | Aplikasi tidak boleh dibuka, ralat sistem |
| **Rangkaian** | Internet perlahan, tidak boleh sambung WiFi |
| **E-mel** | Tidak boleh hantar/terima e-mel |
| **Lain-lain** | Masalah lain yang tidak tersenarai |

## 💻 Mohon Pinjaman Aset ICT

### Langkah Mudah (5 Minit)

```
1. Layari ictserve.motac.gov.my/loan
2. Isi maklumat anda
3. Pilih aset yang diperlukan
4. Pilih tarikh pinjaman
5. Nyatakan tujuan pinjaman
6. Terima terma dan syarat
7. Klik "Hantar Permohonan"
```

### Aset Yang Boleh Dipinjam

| Aset | Tempoh Maksimum |
|------|-----------------|
| Projektor | 14 hari |
| Komputer Riba | 14 hari |
| Kamera | 7 hari |
| Peralatan Audio Visual | 7 hari |

### Proses Kelulusan

```
Permohonan Dihantar → Pegawai Pelulus Terima E-mel → Kelulusan/Penolakan → Anda Dimaklumkan
```

## 🔍 Semak Status Permohonan

### Untuk Tiket Bantuan

1. Gunakan pautan dalam e-mel pengesahan, ATAU
2. Layari **ictserve.motac.gov.my/status**
3. Masukkan nombor tiket (contoh: HD2025000001)
4. Masukkan e-mel anda
5. Klik "Semak Status"

### Untuk Pinjaman Aset

1. Gunakan pautan dalam e-mel pengesahan, ATAU
2. Layari **ictserve.motac.gov.my/status**
3. Masukkan nombor permohonan (contoh: LA2025000001)
4. Masukkan e-mel anda
5. Klik "Semak Status"

## ❓ Soalan Lazim Pantas

**S: Perlukah saya mendaftar untuk menggunakan sistem?**
J: Tidak. Anda boleh menggunakan borang tetamu untuk keperluan segera. Pendaftaran memberikan akses kepada ciri-ciri lanjutan.

**S: Berapa lama tiket saya akan diproses?**
J: Tiket biasa: 1-3 hari bekerja. Tiket kritikal: 24 jam.

**S: Bagaimana jika saya terlupa nombor tiket?**
J: Semak e-mel pengesahan yang dihantar selepas penghantaran.

**S: Bolehkah saya membatalkan permohonan?**
J: Ya, jika permohonan belum diproses.

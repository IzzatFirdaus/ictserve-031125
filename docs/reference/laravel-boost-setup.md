## Overview

Laravel Boost is an MCP (Model Context Protocol) server that provides AI assistants with specialized tools for Laravel development. It includes:

- **15+ specialized tools** (database queries, Artisan commands, route inspection, etc.)
- **17,000+ documentation pieces** with semantic search
- **Version-specific guidelines** for Laravel ecosystem packages
- **Browser log integration** for debugging frontend issues

## Current Configuration

### Environment Settings (`.env`)

```dotenv
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8000
```

**Note**: Boost only runs when:

- `APP_ENV=local` OR `APP_DEBUG=true`
- `BOOST_ENABLED` is not explicitly set to `false`

### Boost Configuration (`config/boost.php`)

```php
'enabled' => env('BOOST_ENABLED', true),
'browser_logs_watcher' => env('BOOST_BROWSER_LOGS_WATCHER', true),
```

**Current Status**: Enabled by default in local environment

### MCP Server Configuration (`.vscode/mcp.json`)

```json
{
    "servers": {
        "laravel-boost": {
            "command": "php",
            "args": ["artisan", "boost:mcp"],
            "env": {
                "APP_ENV": "local",
                "APP_DEBUG": "true",
                "BOOST_ENABLED": "true"
            }
        }
    }
}
```

**Purpose**: The `env` section ensures Boost commands are available even if the main `.env` is temporarily set to production mode.

## How to Use Laravel Boost

### In VS Code

1. **Open Command Palette**: `Ctrl+Shift+P` (Windows) or `Cmd+Shift+P` (Mac)
2. **Type**: "MCP: List Servers"
3. **Select**: `laravel-boost`
4. **Choose**: "Start server"

**Status Indicator**: Look for "laravel-boost" in the status bar (bottom-right)

### In Cursor

1. **Open Command Palette**: `Ctrl+Shift+P` (Windows) or `Cmd+Shift+P` (Mac)
2. **Type**: "/open MCP Settings"
3. **Toggle ON**: `laravel-boost`

### In Claude Code

Laravel Boost is auto-configured via `.claude/mcp.json` (generated by `boost:install`)

If manual setup is needed:

```bash
claude mcp add -s local -t stdio laravel-boost php artisan boost:mcp
```

### In PhpStorm (Junie)

1. Press `Shift` twice to open command palette
2. Search "MCP Settings"
3. Check the box next to `laravel-boost`
4. Click "Apply"

## Keeping Boost Up-to-Date

### Manual Update

```bash
php artisan boost:update
```

This updates:

- AI guidelines to latest versions
- Documentation search index
- Package-specific rules

### Automatic Update (Recommended)

Add to `composer.json`:

```json
{
    "scripts": {
        "post-update-cmd": [
            "@php artisan boost:update --ansi"
        ]
    }
}
```

Now Boost updates automatically when you run `composer update`.

## Troubleshooting

### "No commands defined in 'boost' namespace"

**Cause**: Boost only registers commands in `local` environment or when `APP_DEBUG=true`

**Fix**: Ensure `.env` has:

```dotenv
APP_ENV=local
APP_DEBUG=true
```

Then clear caches:

```bash
php artisan config:clear
php artisan cache:clear
php artisan optimize:clear
```

### MCP Server Won't Start

**Check 1**: Verify PHP is in PATH

```bash
php --version
```

**Check 2**: Test Boost command manually

```bash
php artisan boost:mcp --help
```

**Check 3**: Verify `.vscode/mcp.json` syntax

- No trailing commas
- Valid JSON structure
- Correct command path

### Browser Logs Not Appearing

**Requirement**: Add Blade directive to your layout:

```blade
<head>
    <!-- Other head content -->
    @boostJs
</head>
```

This injects JavaScript to capture console logs and send them to Laravel Boost.

### Documentation Search Returns No Results

**Fix**: Update Boost to refresh documentation index

```bash
php artisan boost:update
```

## Security Considerations

### ⚠️ Development Only

Boost is designed for **local development only**. The service provider automatically disables Boost in production unless explicitly forced.

### Disable in Production

Even though Boost self-disables, you can explicitly prevent it:

```dotenv
# .env.production
BOOST_ENABLED=false
```

### Git Ignore Generated Files

Add to `.gitignore`:

```
boost.json
.claude/
junie/
CLAUDE.md
AGENTS.md
GEMINI.md
opencode.json
.vscode/mcp.json
```

These files are auto-regenerated by `boost:install`, so no need to commit them.

## Custom Guidelines

### Adding Project-Specific Rules

Create files in `.ai/guidelines/`:

```
.ai/
└── guidelines/
    ├── project-structure.md
    ├── coding-standards.blade.php
    └── custom-components.md
```

**Example** (`.ai/guidelines/project-structure.md`):

```markdown
## ICTServe Project Structure

### Module Organization
- All Livewire components use Volt (functional API)
- Services live in `app/Services/`
- Policies are required for all Filament resources

### Naming Conventions
- Controllers: `{Model}Controller` (e.g., `AssetController`)
- Livewire components: `{action}-{model}` (e.g., `create-asset.blade.php`)
- Services: `{Model}Service` (e.g., `AssetService`)
```

### Overriding Boost Guidelines

To replace a built-in guideline, match its path structure:

**Example**: Override Livewire 3 forms guide

Create: `.ai/guidelines/livewire/3/forms.blade.php`

Boost will use your version instead of the default.

## Advanced Configuration

### Custom MCP Server Port

If port conflicts occur, modify the command:

```json
{
    "servers": {
        "laravel-boost": {
            "command": "php",
            "args": ["artisan", "boost:mcp", "--port=9000"]
        }
    }
}
```

### Disable Browser Log Watcher

If browser log collection causes performance issues:

```dotenv
BOOST_BROWSER_LOGS_WATCHER=false
```

### Multiple Projects

Each Laravel project needs its own Boost installation. The MCP server is project-specific and reads from the current working directory.
